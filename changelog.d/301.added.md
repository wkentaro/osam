**Breaking:** Each model in `/api/models` and `Client.list()` reports the required `input_size` and `input_resize`, so a client of this release rejects an older server's model list, and `ModelInfo.input_shape()` gives the size an image is resized to before encoding. An image resized to that size with Pillow's bilinear filter gives the same embedding as the full image, except with EfficientSAM.
