`/api/track` streams current action and frame positions while SAM3 runs, followed by finalized frames and a done or error record. `Client.track(progress=callback)` exposes progress in Python. Disconnecting or raising from the callback cancels between frames and discards a half-applied timeline. Inference errors carry their status code and conflict or missing-image metadata inside the HTTP 200 stream; the Python client preserves these as exceptions. OpenAPI documents the NDJSON records and request validation errors. The video CLI shows progress on stderr while keeping JSON stdout parseable.
